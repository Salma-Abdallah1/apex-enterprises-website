# Apex Enterprises editable website

A responsive company website starter using React, Vite, Lucide icons, and optional Supabase persistent content storage/authentication.

- Public homepage: `/#home`
- Admin dashboard: `/#admin`
- Brand palette: blue `#0866E8`, navy `#0B2D55`, white `#FFFFFF`, black/ink `#101828`
- Slogan: **Idea + Action + Learning = Progress**

Follow `SETUP-SUPABASE.md` for configuration and deployment. Replace placeholder contact details and service copy before launch.
